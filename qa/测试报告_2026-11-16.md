## 三、Bug 清单

### BUG-001：Agnes compat 配置基于错误诊断 ✅ 已修复

| 字段 | 内容 |
|------|------|
| **严重度** | Medium |
| **发现方式** | 真实 API 对照实验 |
| **现象** | 代码声明 `requiresToolResultName: true`，注释称"端点要求 name 字段" |
| **实测** | 端点**不要求** name（带/不带均 200）；真正 400 是 `tool_call_id` 为 undefined 时被 `JSON.stringify` 丢弃 |
| **影响** | 发送端点不需要的字段（无害但误导），注释把运维引向错误方向 |
| **根因** | pi-ai 构造 `{tool_call_id: toolMsg.toolCallId}`，值为 undefined 时该键被整体省略 |
| **修复** | 改为 `false`，注释记录完整实验数据 |
| **验证** | 6 轮工具调用 200；应用内真实对话 200 |

### BUG-002：8 个输入框缺少中文输入法防护 ✅ 已修复

| 字段 | 内容 |
|------|------|
| **严重度** | **High**（影响所有中文用户） |
| **发现方式** | 代码审查 + 对照 `path-input.tsx` 的既有实现 |
| **现象** | `path-input.tsx` 有 `isComposing` + `keyCode===229` 双重防护，但主输入框等 8 处没有 |
| **影响** | 中文用户用输入法打「你好」，按 Enter 选词时**消息被误发送**，发出半成品 |
| **修复** | composer, home, question-dock(×2), practice-dock, reading-thinking(×2), source-folder-tree |
| **验证** | 98/98 相关测试通过 |

### BUG-003：提示词共享片段的代理名未翻译 ✅ 已修复

| 字段 | 内容 |
|------|------|
| **严重度** | Low |
| **发现方式** | 真实浏览器截图 + 英文词扫描 |
| **现象** | 显示「使用方：**Teacher and Prober**」 |
| **根因** | `sectionedSegments()` 是纯函数返回英文 label，调用处只替换了 `Used by` 前缀 |
| **修复** | 渲染时按 `section.*` 键翻译代理名，并做中文标点替换 |
| **验证** | 55/55 设置测试通过 |

## 四、基线既有失败（非本次引入）

以下 15 个用例在**改动前的代码**上运行结果完全相同（用 `git stash` 验证）：

| 文件 | 原因 |
|------|------|
| `auth-store` / `themes` | Windows 路径分隔符 / CSS 读取 |
| `claude-code-*` | 本机未安装 Claude Code CLI |
| `safe-fetch-connector` | Windows 网络栈差异 |
| `session-identity` / `subscription-auth` | 依赖真实 CLI / OAuth 环境 |
| `verify-release` | Windows ESM URL scheme |

**结论**：与本次改动无关。
