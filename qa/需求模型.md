## goal（目标与成功标准）

**一句话**：让 LearnHarness 桌面/网页应用完整支持简体中文界面，并新增 Agnes AI 作为内置 OpenAI 兼容模型提供商。

**成功标准**：
1. 界面全部可见文案在 `zh-CN` 下显示中文，无英文残留、无键名泄漏（形如 `xxx.yyy.zzz`）
2. 语言可在 设置 → 通用 → 语言 中切换，切换后界面即时生效
3. Agnes AI 出现在 设置 → 服务提供商，配置 API key 后模型可用于会话
4. 使用 Agnes 时工具调用正常工作（不再 400）
5. 现有 419 个测试无新增回归

## scope（功能范围）

### 范围内
| 区域 | 内容 |
|------|------|
| 核心 Web UI | `components/` 下 87 个文件的可见文案 |
| 设置界面 | 8 个分区的标签/提示/按钮/状态 |
| 5 个内置插件 | 记忆卡片、代码练习、绘图板、学科代码块、组件示例库 |

- ❌ 不支持除 `zh-CN` / `en` 外的其他语言
- ❌ 不修改源提示词文件（`src/agent/prompts/` 保持英文，便于上游合并）
- ❌ 不翻译模型 ID、API 标识符、文件路径、键盘按键名
- ❌ 不翻译服务端面向开发者的技术诊断信息
- ❌ 不引入 URL 语言前缀（`/zh/`、`/en/`）

## states（状态流转）

### 语言状态
```
未设置 --首启--> zh-CN（工厂默认）
zh-CN --用户切换--> en --router.refresh()--> 服务端重读记录 --> en 界面
en --用户切换--> zh-CN --同上--> zh-CN 界面
```

### Agnes 提供商状态
```
未配置 --填入 key--> 已配置 --发起工具调用--> 正常（requiresToolResultName 修复后）
未配置 --发起调用--> 403/未配置（pi-ai 诚实失败）
```

## exceptions（异常预期）

| 场景 | 预期行为 | evidence |
|------|---------|---------|
| 语言包缺失某键 | 显示键名（next-intl 默认行为）⚠ | 观测于测试 |
| `settings.json` 损坏 | 回退工厂默认（zh-CN） | `i18n/request.ts` catch |
| 未知语言值 | 通过 `isAppLocale` 拒绝，回退默认 | `i18n/config.ts` |
| Agnes key 缺失 | pi-ai 诚实失败（未配置） | 设计如此 |
| 插件词典缺键 | 回退英文原文 | 各插件 `t()` 实现 |
| 未知错误消息 | 原样显示英文 | R8 |
